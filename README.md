# Peaky Minds — учебный DevOps-стенд

Готовый сервис заявок и настоящая цепочка CI для курса https://stepik.org/course/301758.
Ученик работает командами Linux, Git, Docker, Compose и HTTP. Написание Python не требуется.

Исходный код Go предназначен для воспроизводимой авторской сборки. Изучать его для прохождения курса не нужно.
Workflow проверяет runtime, собирает готовый бинарник и образ, запускает положительный HTTP-сценарий и проверяет намеренно неисправную поставку. Публикация образа выполняется только из main после успешных проверок.

## Получить учебный комплект

Раздел Releases содержит готовый комплект Linux amd64; контрольная сумма опубликована рядом. Учебные файлы не содержат ключей доступа к серверу автора.

## Что доказывает CI

Run привязан к Git SHA, образ — к registry digest. Отдельные HTTP-запросы создают и читают запись, затем подтверждают её сохранность после перезапуска. Наличие этого CI не означает подключения автоматических баллов Stepik: это отдельная интеграция.

## Практика

Используйте отдельную учебную Linux-машину. Не подключайте Docker socket общего рабочего сервера и не запускайте лабораторные с реальными пользовательскими данными.

## Дополнительный тренажёр редакции 5

В релизе `course-v5` скачайте `practice-v5.tar.gz` и `SHA256SUMS-practice-v5`.
Проверьте `sha256sum -c SHA256SUMS-practice-v5`, создайте отдельный каталог
`mkdir -p "$HOME/peaky-v5"` и распакуйте `tar -xzf practice-v5.tar.gz -C "$HOME/peaky-v5"`.
Это дополнение к сервисному комплекту peaky-kit, а не его замена.

`bash "$HOME/peaky-v5/practice/v5/practice.sh" prepare navigation` печатает уникальную
рабочую папку и команду самопроверки. Доступны navigation, create, copies, reading,
search, streams и git. Выполните условия урока в этой папке, затем вызовите напечатанную
команду check. Повторная prepare создаёт новую попытку и сохраняет прежнюю.

`practice/v5/check-http.sh` принимает BASE собственного экземпляра. Он проверяет
готовность, POST, отдельное чтение с совпадающими полями и отказ на неверный ввод.
Баллы Stepik за текст команды и локальная самопроверка реального состояния — разные
виды проверки. Эти скрипты не отправляют баллы в Stepik.

Контейнерный тест поддерживает `IMAGE_REF=ваш-тег bash scripts/check-container.sh`.
Образ должен быть построен заранее. Для параллельной проверки выберите свободный
`CONTAINER_TEST_PORT`; тест удаляет только собственный временный контейнер и том.
